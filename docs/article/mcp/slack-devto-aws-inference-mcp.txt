An MCP server that runs my six-backend Gemma 4 demo on AWS: list, launch, health-check, read logs, ask and tear down Bedrock, SageMaker, EC2 g6 and g5g, Inferentia2 and Trainium from one chat session.
Eight tools in one Python file, each marked read-only, write or destructive; health checks and logs run on the instance through SSM Run Command, with no inbound ports.
Live run: g6 answered 12.2 minutes after launch, inf2 20.4 minutes after, and billing read 0 twenty-one seconds after teardown.
